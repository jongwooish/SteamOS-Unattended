## 1. スクリプト（実機の Steam Deck）

- **最初は `--dry-run` で実行します。** 何をインストール・変更するかを表示するだけで、何も変更しません。
- **sudo が必要なのは `60-etc-keep` モジュールだけです。** deck のパスワードを設定していない場合（`passwd`）、このモジュールは警告を残してスキップされます。他のモジュールは通常どおり進みます。
- **`dotfiles/` のファイルは `$HOME` のファイルを上書きします。** 内容が異なる場合は、上書き前に元のファイルを `~/.local/state/steamos-unattended/backup/<時刻>/` にバックアップします。
- **`~/.bashrc` には 1 行だけ追加します**（`~/.bash_aliases` を読み込む行）。既にあれば再度追加しません。
- **初回実行は 5〜15 分かかります。** コンテナイメージと Flatpak アプリをダウンロードするためです。止まって見えても待ってください。
- **ハングル入力は次回ログインから有効になります。** 切り替えは Ctrl+Space または 한/영 キーです。
- **バックアップは既定で `~/Backups` に保存されます。** 同じディスクなので機器の故障には備えられません。`config/backup.conf` で SD カードや NAS を指定することをおすすめします。
- **`/etc/**` のような広いパターンを保持リストに入れないでください。** 今後の SteamOS アップデートが `/etc` を更新できなくなり、不具合の原因になります。必要なファイルだけを書きます。

## 2. SteamOS システム

- **`steamos-readonly disable` は使いません。** このプロジェクトはシステム領域（`/usr`）に一切触れません。そこにインストールしたものはアップデートで消えます。
- **`pacman -Sy` は実行しません。** pacman のデータベースが読み取り専用領域にあるため失敗し、無理に行うとシステムパッケージのバージョンがずれます。

## 3. VMware テスト環境

- **ゲームモードは VMware では動作しません。** 仮想 GPU に Vulkan がないためです。「Return to Gaming Mode」を押すと黒い画面になり、SSH で `sudo reboot` するとデスクトップに戻ります。
- **インストール後のシステムはデスクトップ表示まで 1〜2 分かかります。** 黒い画面でも最低 2 分は待ってください。
- **SteamOS のカーネルが更新されたら vmwgfx ドライバーを再ビルドします。** ドライバーのサービスは起動を妨げないので、SSH で入って修正できます。
- **ディスクをフォーマットする前に、必ず `lsblk` で名前とサイズを確認します。** リカバリーディスク（`sda`）を誤って選ぶと作業環境が消えます。
- **`.vmx` のパスは正確に指定します。** 誤ったパスを指定すると *その* VM がスナップショットに戻ります。VM が多い場合は特に注意してください。
- **どこでコマンドを入力しているか確認します。** `PS C:\…>` は Windows、`(deck@steamdeck ~)$` は VM の中です。Windows のコマンドは VM の中では動きません。
- **VM では 한/영 キーを Windows や VMware が先に受け取ることがあります。** Ctrl+Space を使ってください。
